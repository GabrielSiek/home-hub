# Codebase findings

An audit of the existing launcher (`src-tauri/src`, `src/`, `companion/src`) made on 2026-10-27,
before the server split. The old code is never edited: each finding is fixed in the copy under
`refactor/`. **Fixed in** names the milestone of `docs/ARCHITECTURE.md`, and **Status** is updated
as work lands.

Paths are relative to `src-tauri/src/` unless they start with `src/`, `companion/` or a file at
the project root.

## For you, outside the refactor

| What | Why | Do |
|---|---|---|
| `.env` holds `POSITIVO_EMAIL` and `POSITIVO_PASSWORD` | Nothing reads them since the one-time IR-code import, and the project folder syncs to OneDrive | Delete both lines and change that account's password |
| `.env` (real API keys) and `src-tauri/target` (GBs) live in OneDrive | Keys leave the house; build output churns the sync | After the move the keys live in `C:\ProgramData\TVLauncher\server`; the refactor builds to `C:\TVLauncher\build` |
| No git history (no commits at all) | Nothing to diff or roll back to | A baseline commit before the refactor goes further |

## Security

| # | Finding | Evidence | Fix | Fixed in | Status |
|---|---|---|---|---|---|
| S1 | **Any web page opened on a home device can drive the launcher.** `call()` parses any POST body as JSON whatever its Content-Type, so a page can send a "simple" cross-site request (CSRF). The events WebSocket has no Origin check, so any page can read device states, what's playing and what the assistant last heard. With no Host check, DNS rebinding also makes every `/api/*` read and `/api/file` (photo albums) readable. | `companion/mod.rs:175-189`, `:219-262`, `:148-171` | Host allowlist; Origin must equal Host on POST and WebSocket; POST must be `application/json` (`audio/wav` for transcription) | M1a | done: server |
| S2 | **`launch_app_at` opens any URL in the logged-in Edge profile.** A web app's id plus an arbitrary URL goes straight to `--app=`. Through S1 a page can open anything with the streaming sign-ins. | `launcher.rs:100-127`, `:324` | Forwarded calls must be https on that app's own host | M1a | done: forwarded calls only open the app's own https pages |
| S3 | **API keys end up in error text.** TMDB (v3), Last.fm and Steam keys go in query strings; reqwest's error message includes the full URL; that text becomes the command's error, sent to the companion and printed. | `tmdb.rs:103`, `spotify/popular.rs:39`, `games/steam.rs:226`, `error.rs:14,28-31`, `companion/mod.rs:187` | `kit::http` strips URLs from errors (`without_url`); bearer headers where the API accepts them (YouTube already does, `sports/mod.rs:676`) | M1a | done: server (kit::Error); TV app logs to a file |
| S4 | **Every secret reaches the UI.** `get_settings` returns all keys and secrets as is. `"csp": null` and an asset scope of `$APPDATA/**` let the webview load any file in the data folder, token files included. | `commands.rs:394-396`, `tauri.conf.json:26-29` | Server masks secrets (write-only); the TV app gets a CSP and scopes limited to icons, art and photos | M1a | done: server masks; TV app has a CSP and asset scopes for icons, art, photos and retro art |
| S5 | **Risky commands with no limits.** `remote_text` types any length; the assistant can open any Start-menu program; `companion_hello` registers unlimited screens. | `companion/tv.rs:153`, `assistant/tools.rs:392-434`, `smarthome/rooms.rs:332` | `remote_text` ≤ 500 chars; screens capped; tools allowlisted per caller | M1a | done: screens capped; remote_text at most 500 characters |

| S9 | **A saved PID can kill the wrong process** after reuse (the sync browser cleanup). | `watch/sync.rs:158-176` | Check the process image name before killing | M2 | |

## Data safety and reliability

| # | Finding | Evidence | Fix | Fixed in | Status |
|---|---|---|---|---|---|
| D1 | **Silent data loss.** 27 modules (about 40 files) load with a fallback to defaults and save with a plain `fs::write`; no JSON write is atomic (the only renames are a folder swap and installers). A half-written file (power cut, OneDrive conflict) loads as empty **with no log**, and the next save erases scenes, automations, alarms or rooms. No file has a schema version. | `smarthome/scenes.rs:86-91`, `clock/mod.rs:255-258`, `smarthome/rooms.rs:111-117`, `history.rs:31-35`, `watch/store.rs:152-156`; renames only at `photos/google.rs:530`, `assistant/speech.rs:237`, `retro/install.rs:479` | `kit::JsonStore`: temp file + flush + rename (retrying sharing violations), a version field, and a file that fails to parse is renamed `.corrupt-<time>` and logged, never overwritten | M1 (every ported store) | done: every server store |
| D2 | **Release builds throw every log line away**: the exe has no console and the code prints 115 times (76 `eprintln!`, 39 `println!`) with no log file. | `main.rs:2` | `tracing` to a daily file in the data folder | M1a | done: server |

The companion polls `tv_now` every 10 s because volume changes send no event. A lagging socket is skipped silently. | `spotify/mod.rs:679-685,747`, `smarthome/tuya.rs:313`, `companion/src/live.ts:90`, `companion/mod.rs:242` | Emit on change; a `tv` event on volume; `resync` to a lagging socket | M1 / M2 | done: LAN emit on change, resync; Spotify M2 |
